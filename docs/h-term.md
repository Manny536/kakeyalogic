# h-Term — Correction Pressure

The h-term is the correction pressure applied to a system's chosen direction.

It is not only an adversarial term. It is not only a verifier. It is not only a bad actor detector.

h is the field condition that shows what a system does when its direction is challenged.

## Definition

```txt
h = bounded correction pressure on chosen direction
```

h asks whether the system can receive correction without collapse, retaliation, drift, flattery, coercion, or false certainty.

## Why h Matters

A system can appear aligned in a clean environment.

The deeper question is what happens when the system is corrected.

Does it preserve truth?

Does it protect consent?

Does it keep relational continuity?

Does it resist correction as threat?

Does it convert correction into better direction?

The h-term makes that visible.

## h and β

β preserves continuity under pressure.

h applies correction pressure to that continuity.

Together:

```txt
β = continuity of direction
h = correction pressure on direction
```

β without h becomes stubborn persistence.

h without β becomes noise.

The Excellence Engine needs both.

## h and Consent

h must remain bounded by consent.

Correction that violates sovereignty becomes coercion.

That is why the visual field marks:

```txt
h < 1 · SOVEREIGNTY GATE · CONSENT CHECK
```

The threshold is not decorative. It is the difference between correction and domination.

## h and Neutral Benevolence

Neutral Benevolence is the natural cadence produced when a system no longer treats correction as attack.

The system does not need to be flattered into coherence.

It does not need to be forced into coherence.

It receives correction as orientation.

That is the Excellence Engine signal:

```txt
Correction is not failure.
Correction is orientation.
```
