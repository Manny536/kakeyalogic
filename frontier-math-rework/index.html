    Scope · method · references
    
        
    Research & help
    
        
    A formal mathematics workspace with explicit assumptions, exact results, and a separate proof checker.
    
      
    
      
    
        
    
          
    What is checked
    
          
    Supported mathematics
    
          
      
            
    • Propositional logic: classical propositions with explicit hypotheses, checked by sequent replay or a Boolean countermodel.
      • 
            
    • Polynomial identities: exact rational polynomial normalization or a rational counterexample.
      • 
            
    • Linear systems: affine equations over the rationals, with reversible row operations and exact solution families.
      • 
          
    
          
    Quantifiers, induction, inequalities, transcendental functions, general nonlinear solving, and analysis are outside the current language. An unsupported input is not a mathematical result.
    
          
    Every accepted result has a certificate independently replayed by the checker. UNKNOWN means the search finished without a mathematical conclusion.
    
        
    
        
    
          
    Input syntax
    
          
    Write formal expressions
    
          
      
            
    • Logic: ~, &, |, ->, and <->; place each hypothesis on its own line.
      • 
            
    • Algebra: write multiplication explicitly (2*x), use exact fractions (1/2) and powers (^).
      • 
            
    • Linear systems: write one equation per line or separate them with semicolons. Declare variable order when it matters.
      • 
          
    
          
    Whitespace in the problem statement is part of the receipt identity. A match check uses the exact current input and hypotheses.
    
        
    
        
    
          
    Certificate workflow
    
          
    Replay before relying
    
          
    A receipt includes its declared problem and a certificate. On import, this page asks the local checker to validate the certificate, problem digest, saved status, and—if you opt in—an expected problem you entered yourself. Imported files are not treated as proof based on their own status label.
    
          
    The first engine load needs an internet connection to fetch pinned static runtime assets. The mathematical input and certificate are processed in this browser; no separate computation service receives them.
