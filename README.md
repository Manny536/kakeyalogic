```txt
Peter Ochs, Yunjin Chen, Thomas Brox, Thomas Pock
"iPiano: Inertial Proximal Algorithm for Nonconvex Optimization"
SIAM Journal on Imaging Sciences, 2014
```

```txt
min_x h(x) = f(x) + g(x)
```

```txt
  x_n - α_n∇f(x_n) + β_n(x_n - x_{n-1})
)
```
